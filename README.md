# Quidly

Личный учёт финансов. Работает в браузере и ставится на телефон как приложение.
Все данные хранятся только на устройстве — без серверов и регистрации.

**Адрес:** https://bobryakov.github.io/quidly/

## Что уже есть

**Этап 2 — счета, категории, быстрый ввод**
- Первый запуск: знакомство «Сколько у вас сейчас денег?» — счета с текущими остатками.
- Быстрый ввод: «+» → сумма на крупной клавиатуре → тап по категории — готово. Частые категории — первыми.
- Расход, доход и перевод между своими счетами (перевод не считается ни расходом, ни доходом).
- Дата, счёт (по умолчанию — последний использованный) и комментарий — по желанию.
- Правка и удаление операции, после удаления — «Отменить».
- Экран «Операции»: по дням, по месяцам, фильтр по типу, поиск.
- Настройки → Счета (баланс, архив) и Категории (добавить, переименовать, эмодзи, цвет, объединить).
- Данные хранятся в базе браузера на устройстве (IndexedDB).

**Этап 1 — каркас**
- 5 экранов (Главная, Операции, Аналитика, Цели, Настройки) и нижнее меню.
- Светлая, тёмная и «как в системе» тема.
- Установка на телефон (PWA) и работа без интернета.
- Плашка «Вышла новая версия → Обновить»: обновление включается только по нажатию.
- Автопубликация на GitHub Pages при каждой отправке в ветку `main` (с прогоном тестов).

Полное описание функций — в [docs/SPEC.md](docs/SPEC.md), текущий статус — в [docs/STATUS.md](docs/STATUS.md).

## Команды

| Команда | Что делает |
|---|---|
| `npm install` | Ставит пакеты (один раз и после обновлений). |
| `npm run dev` | Запускает приложение на ноутбуке: http://localhost:5173/quidly/ |
| `npm test` | Прогоняет тесты. |
| `npm run build` | Собирает версию для публикации в папку `dist`. |
| `npm run preview` | Показывает собранную версию: http://localhost:4173/quidly/ |

## Стек

React + TypeScript + Vite, Tailwind, Dexie (база на устройстве), vite-plugin-pwa, Framer Motion, React Router, Vitest.
Дальше добавятся Recharts, SheetJS, PapaParse.

## Для разработчика

- Схема базы — `src/db/db.ts`. Уже выпущенные версии схемы **не менять**: только добавлять `version(N+1)` с миграцией.
- Все изменения данных — через `src/db/repo.ts` (там проверки).
- Расчёты (`src/lib`) и работа с базой покрыты тестами (`*.test.ts`).
