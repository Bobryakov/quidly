# Примеры банковских выписок

Сюда кладутся **реальные, обезличенные** выписки — по ним пишутся правила чтения (парсеры) для импорта.

- Т-Банк — `tbank.csv` (или `tbank.xlsx`, `tbank.pdf`)
- Сбер — `sber.xlsx` (или `sber.csv`, `sber.pdf`)
- Альфа-Банк — `alfa.xlsx` (или `alfa.csv`, `alfa.pdf`)

⚠️ Все файлы в этой папке, кроме этого описания, **не отправляются на GitHub** (так настроено в `.gitignore`).
Для автоматических проверок (тестов) делаются отдельные выдуманные файлы с тем же устройством, что у настоящих.

Как выгрузить и обезличить выписки — в `docs/guides/08-vypiski-dlya-importa.md`.
