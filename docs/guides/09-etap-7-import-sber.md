# Этап 7: импорт выписки Сбера — отправить на GitHub и попробовать

Время: около 15 минут. Компьютер: Windows, PowerShell.

Новые файлы я уже положил в папку `quidly`. Добавились библиотеки для чтения PDF, CSV и Excel, поэтому **нужен `npm install`**.

---

## Шаг 1. Откройте PowerShell в папке проекта

```
cd $HOME\Projects\quidly
```

✅ **Должны увидеть:** строку, которая заканчивается на `\Projects\quidly>`

---

## Шаг 2. Поставьте новые пакеты

```
npm install
```

✅ **Должны увидеть:** `added 7 packages` (число может отличаться) и, как и раньше, `14 vulnerabilities (2 moderate, 12 high)` — это те же предупреждения инструментов сборки, новых нет.

ℹ️ Библиотека для Excel (SheetJS) скачивается с сайта её разработчиков `cdn.sheetjs.com` — так они сами рекомендуют, там свежая версия без уязвимостей.

---

## Шаг 3. Прогоните тесты

```
npm test
```

✅ **Должны увидеть:** `Tests  200 passed (200)`.

ℹ️ Одна из проверок читает вашу настоящую выписку из `samples` и сверяет суммы с итогами Сбера. На GitHub этой выписки нет, поэтому там та же проверка просто пропускается.

## Шаг 4. Убедитесь, что выписка не уйдёт на GitHub

```
git status --short --untracked-files=all
```

✅ **Должны увидеть:** список изменённых файлов программы — и **ни одной** строки с `samples/Выписка…pdf`.

❌ Если строка с выпиской есть — ничего не отправляйте, пришлите скриншот.

## Шаг 6. Обновите приложение на телефоне

Quidly → плашка **«Вышла новая версия»** → **Обновить** (или закройте приложение полностью и откройте снова).

✅ **Должны увидеть:** в «Настройках» пункты **📥 Импорт выписки** и **🪄 Правила импорта**.

---

## Шаг 7. Подготовьте счета (один раз)

Чтобы переводы между вашими счетами распознавались, а не считались тратами:

- Счёт карты Сбера назовите так, чтобы в названии было **«Сбер»** («Настройки → Счета» → тап по счёту → название). Тогда он выберется для импорта сам.
- Если переводите на **Т-Банк** — заведите счёт со словом «Т-Банк» в названии.
- Есть **«Наличные»** — снятие в банкомате станет переводом на них (комиссия — отдельной тратой).
- Если у вас в Сбере есть **второй счёт** (накопительный, вклад), заведите его со словом «Сбер» — переводы «SBOL» станут переводами на него.

## Шаг 8. Импортируйте выписку

1. В приложении **СберБанк Онлайн** закажите выписку по счёту карты (как в прошлый раз) и **сохраните PDF в «Файлы»** телефона (кнопка «Поделиться» → «Сохранить в Файлы»).
2. В Quidly: **«Настройки → Импорт выписки» → «Выбрать файл выписки»** → выберите этот PDF.
3. Проверьте вверху: **«✓ Прочитано … операций — суммы сходятся с итогами выписки»**.
4. Если появится блок **«По выписке на … на счёте …, а в Quidly после импорта будет …»** — оставьте галочку **«Выровнять остаток по выписке»**. Так бывает, если остаток вы вписали «на сегодня», а импортируются прошлые операции.
5. Пролистайте список:
   - тап по значку категории — сменить (запомнится для этого магазина);
   - «⇄ на «Т-Банк» ✎» — перевод на ваш счёт; тап — выбрать другой счёт или «это расход»;
   - «⇄ себе?» — если это перевод между своими счетами;
   - «похоже на вашу запись» — такая трата уже внесена вручную, галочка снята.
6. Нажмите **«Импортировать: …»**.

✅ **Должны увидеть:** экран «Операции» со всеми операциями из выписки, а баланс счёта — как в Сбере.

ℹ️ Импортировать ту же выписку второй раз не страшно: всё будет помечено «уже импортировано».

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| «Этот PDF пока не умею читать» | Скорее всего, это другой вид выписки. Пришлите мне скриншот первой страницы. |
| «⚠️ Суммы не сходятся с итогами выписки» | Ничего не импортируйте, пришлите скриншот — разберусь. |
| `npm install` — ошибка про `cdn.sheetjs.com` | Проверьте интернет и повторите; не помогло — пришлите скриншот. |
| В Actions красный крестик ❌ | Нажмите на запуск, затем на красный шаг и пришлите скриншот. |
| Любая другая ошибка | Скопируйте текст ошибки или сделайте скриншот и пришлите мне. |
