# Подготовка ноутбука к работе над Quidly

Время: около 10 минут. Компьютер: Windows.

---

## Шаг 1. Откройте PowerShell

PowerShell — окно, куда вводятся текстовые команды.

Нажмите «Пуск» → наберите `PowerShell` → нажмите Enter.

Команды ниже копируйте и вставляйте в это окно (правый клик мыши = вставить), затем нажимайте Enter.

---

## Шаг 2. Установите Git

Git — программа, которая хранит историю версий кода.

```
winget install --id Git.Git -e
```

Если спросит про согласие с условиями — введите `Y` и нажмите Enter.

✅ **Должны увидеть:** «Успешно установлено» (или «Successfully installed»).

---

## Шаг 3. Установите Node.js

Node.js — среда, на которой собирается и запускается приложение.

```
winget install --id OpenJS.NodeJS.LTS -e
```

✅ **Должны увидеть:** «Успешно установлено».

---

## Шаг 4. Перезапустите PowerShell и проверьте установку

Закройте окно PowerShell и откройте заново (иначе оно не «увидит» новые программы). Затем по очереди:

```
git --version
```
✅ Строка вида `git version 2.xx.x.windows.1`

```
node -v
```
✅ Строка вида `v24.x.x` — первое число должно быть **22 или больше**.

```
npm -v
```
✅ Просто номер версии, например `11.x.x`.

---

## Шаг 5. Создайте папку проекта

```
mkdir $HOME\Projects\quidly
```

✅ **Должны увидеть:** небольшую таблицу со строкой `quidly`.

---

## Шаг 6. Откройте этот чат в приложении Claude на ноутбуке

1. Если приложения Claude на ноутбуке нет — скачайте с claude.ai/download.
2. Откройте в нём этот чат и напишите, например, «я дома».
3. Я попрошу доступ к папке `quidly` — разрешите.

Дальше я сам положу туда CLAUDE.md и SPEC и начну этап 1.

---

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| «winget не найден» | Скачайте установщики вручную: git-scm.com и nodejs.org (кнопка с пометкой **LTS**). Ставьте с настройками по умолчанию, нажимая «Далее». Затем — шаг 4. |
| `node -v` или `git --version` пишет «не распознано» | Закройте и снова откройте PowerShell. Не помогло — перезагрузите ноутбук. |
| Любая другая ошибка | Сделайте скриншот или скопируйте текст ошибки и пришлите мне. |
