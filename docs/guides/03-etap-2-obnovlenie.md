# Этап 2: отправить обновление на GitHub и проверить на телефоне

Время: около 10 минут. Компьютер: Windows, PowerShell.

Новые файлы я уже положил в папку `quidly`. Осталось: поставить новые пакеты, прогнать тесты, отправить изменения на GitHub и обновить приложение на телефоне.

---

## Шаг 1. Откройте PowerShell в папке проекта

```
cd $HOME\Projects\quidly
```

✅ **Должны увидеть:** строку, которая заканчивается на `\Projects\quidly>`

---

## Шаг 2. Поставьте новые пакеты

На этом этапе добавилась библиотека для хранения данных на устройстве (Dexie), её нужно скачать.

```
npm install
```

✅ **Должны увидеть:** строку вида `added 3 packages` (число может отличаться).

ℹ️ Предупреждения `4 moderate severity vulnerabilities` и `npm warn deprecated glob` — те же, что и раньше, это нормально.

---

## Шаг 3. Прогоните тесты

```
npm test
```

✅ **Должны увидеть:** `Tests  51 passed (51)`.

---

## Шаг 4 (по желанию). Посмотрите на ноутбуке

```
npm run dev
```

Откройте http://localhost:5173/quidly/ — появится экран «Привет! Это Quidly». Остановить: **Ctrl+C** в PowerShell.

ℹ️ На ноутбуке и на телефоне данные **разные**: у каждого браузера своя база. Можно смело тренироваться на ноутбуке.

---

## Шаг 5. Сохраните и отправьте изменения на GitHub

По очереди:

```
git add .
```
✅ Ничего (или предупреждения про `LF`/`CRLF` — это нормально).

```
git commit -m "Этап 2: счета, категории, быстрый ввод"
```
✅ Строка вида `[main 1a2b3c4] Этап 2: ...` и `N files changed`.

```
git push
```
✅ В конце строка `main -> main`.

---

## Шаг 6. Дождитесь публикации

Откройте https://github.com/Bobryakov/quidly/actions — через 1–3 минуты у запуска «Этап 2: …» будет **зелёная галочка** ✅.

---

## Шаг 7. Обновите приложение на телефоне

1. Откройте Quidly на телефоне.
2. Сверху появится плашка **«Вышла новая версия Quidly»** → нажмите **Обновить**.
   Если плашки нет — полностью закройте приложение (смахните из списка открытых) и откройте снова. Иногда нужно сделать это два раза.
3. Должен открыться экран **«Привет! Это Quidly»**. Впишите, сколько сейчас на карте и наличными, нажмите **Начать**.

### Что попробовать

- **«+» → 350 → 🛒 Продукты** — трата записана, баланс уменьшился.
- **Доход:** «+» → вверху «Доход» → сумма → 💰 Зарплата.
- **Перевод:** «+» → «Перевод» → сумма → «Откуда» / «Куда» → **Перевести**. Общий баланс не меняется.
- **Другая дата или комментарий:** в панели «+» кнопки 📅 и 💬 (до выбора категории).
- **Исправить или удалить:** тап по операции в списке → поменяйте → **Сохранить** или **🗑 Удалить**. После удаления внизу есть **Отменить**.
- **Настройки → Счета:** добавить счёт, поправить «Сейчас на счёте», убрать в архив.
- **Настройки → Категории:** добавить, переименовать, сменить эмодзи и цвет, объединить две категории.

---

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| `npm test` — красные строки `failed` | Пришлите скриншот, ничего не отправляйте на GitHub. |
| `git push` пишет `rejected` | Пришлите скриншот — подскажу. |
| В Actions красный крестик ❌ | Нажмите на запуск, затем на красный шаг и пришлите скриншот. На сайте при этом остаётся прошлая рабочая версия. |
| На телефоне всё ещё старая версия | Закройте приложение полностью и откройте снова (до двух раз). |
| Любая другая ошибка | Скопируйте текст ошибки или сделайте скриншот и пришлите мне. |
