# Этап 7, подготовка: выгрузить выписки из банков

Время: 20–40 минут. Нужен компьютер (на сайте банка выгрузка обычно богаче, чем в приложении на телефоне).

Импорт выписок я буду писать **только по настоящим файлам** ваших банков — так каждый банк будет читаться без ошибок. Для этого нужны примеры: по одной выписке из каждого банка, где у вас есть карта.

> **Выписка** — файл со списком ваших операций за период: дата, сумма, описание («ПЯТЁРОЧКА 1234»), иногда категория банка и код вида покупки (MCC).

---

## Что нужно

- **Период:** 1–2 месяца, чтобы в файле было хотя бы 20–30 операций.
- **Разные операции, если есть:** покупки в магазинах, поступление зарплаты, перевод другому человеку, **перевод между своими счетами** (например, с Т-Банка на Сбер), возврат покупки, снятие наличных, оплата по СБП, покупка в валюте.
- **Формат:** лучше всего **таблица** — CSV или Excel (.xlsx). Если банк даёт только PDF — берите PDF.

Если какой-то пункт меню в банке называется чуть иначе или его нет — не страшно: сделайте скриншот и пришлите мне, разберёмся.

---

## Шаг 1. Т-Банк (на компьютере)

1. Войдите в личный кабинет на сайте **tbank.ru**.
2. Откройте раздел **«Операции»**.
3. Выберите карту (или «Все счета») и период — например, последние 2 месяца.
4. Найдите кнопку выгрузки (значок «⤓» или «Скачать / Выгрузить») и выберите **CSV**. Если предлагают ещё и **XLS** — скачайте оба файла.

По отзывам клиентов, в личном кабинете Т-Банка можно выгрузить операции в CSV, XLS и OFX, а в выгрузке есть MCC-код каждой покупки. В приложении на телефоне чаще бывает только PDF.

---

## Шаг 2. Сбер (на компьютере)

1. Войдите в **веб-версию СберБанк Онлайн** (online.sberbank.ru).
2. Нажмите на карту → найдите **«Выписки и справки»** или **«Отчёт по карте»**.
3. Выберите выписку **по счёту карты** за произвольные даты (те же 1–2 месяца).
4. Если есть выбор формата — **Excel**. Иногда формат меняется в окне отправки на почту (значок карандаша рядом с форматом).
5. Если Excel нет — скачайте **PDF**.

---

## Шаг 3. Альфа-Банк (на компьютере)

1. Войдите в **Альфа-Онлайн** на сайте alfabank.ru.
2. Откройте **«Справки и выписки»** → **«Выписка по счёту»** (или нажмите на счёт карты → «Выписка»).
3. Укажите период.
4. Если можно выбрать формат — **Excel**, иначе **PDF**.

---

## Шаг 4. Уберите личные данные (обезличивание)

Мне нужна **структура** файла (какие колонки, как записаны даты и суммы), а не ваши персональные данные.

**Замените:**
- ваши ФИО и ФИО людей, которым вы переводили (например, на «Клиент» и «Получатель»);
- номера телефонов (например, на `+70000000000`);
- полные номера карт и счетов — оставьте только последние 4 цифры, остальное замените нулями;
- адреса, если встречаются.

**Не меняйте:**
- названия колонок, их порядок, разделители;
- даты и суммы (как записаны — так и оставьте);
- названия магазинов («ПЯТЁРОЧКА», «ЯНДЕКС.ТАКСИ») — по ним работает автоматический выбор категории;
- категории банка и MCC-коды.

### Как заменить в CSV (Т-Банк)

⚠️ **Не открывайте CSV в Excel и не сохраняйте его из Excel** — Excel незаметно меняет формат файла (даты, разделители, кодировку).

1. Правый клик по файлу → **«Открыть с помощью»** → **«Блокнот»**.
2. Нажмите **Ctrl+H** («Заменить»).
3. «Что»: например, `Иванов Иван` → «Чем»: `Клиент` → **«Заменить все»**. Повторите для каждого имени и номера.
4. Сохраните: **Ctrl+S**.

### Как заменить в Excel (.xlsx)

1. Откройте файл в Excel → **Ctrl+H** → те же замены → **«Заменить все»**.
2. Сохраните в том же формате (**.xlsx**) — Ctrl+S.

### PDF

Отредактировать PDF без специальных программ сложно. Два варианта — выберите сами:
- **Положить PDF как есть.** Файл останется только на вашем ноутбуке и в моей рабочей среде, на GitHub он не попадёт. Выберите период покороче.
- **Не давать PDF.** Тогда для этого банка я сделаю «универсальный импорт» (вы сами укажете, где какая колонка), а пресет банка добавим позже.

## Шаг 6. Проверьте, что выписки не уйдут на GitHub

Репозиторий на GitHub публичный, поэтому я настроил Git так, чтобы он **не видел** файлы в `samples` (кроме описания папки). Проверьте:

```
cd $HOME\Projects\quidly
git status --short --untracked-files=all
```

✅ **Должны увидеть:** строки про `.gitignore`, `samples/README.md` и файлы в `docs/` — и **ни одной** строки вида `samples/tbank.csv`, `samples/sber...`, `samples/alfa...`.

❌ Если строки с вашими выписками **есть** — ничего не отправляйте и пришлите мне скриншот.

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Не нашёл, где скачать выписку | Скриншот экрана карты/счёта на сайте банка — подскажу. |
| Банк даёт только PDF | Нормально — кладите PDF (см. шаг 4) или пропустите этот банк. |
| Файл открылся «кракозябрами» в Блокноте | Ничего не сохраняйте, просто закройте и положите файл без изменений — разберусь сам. |
| В `git status` видны файлы из `samples` | Ничего не отправляйте, пришлите скриншот. |
