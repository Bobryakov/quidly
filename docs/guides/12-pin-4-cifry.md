# Правка: PIN из 4 цифр — отправить на GitHub

Время: 5 минут. Компьютер: Windows, PowerShell. `npm install` не нужен.

Новые файлы уже в папке `quidly`.

## Шаг 1. Тесты

```
cd $HOME\Projects\quidly
```
```
npm test
```

✅ **Должны увидеть:** `Tests  266 passed (266)`.

## Шаг 2. Отправка на GitHub

```
git add .
```
```
git commit -m "PIN из 4 цифр"
```
```
git push
```

✅ В конце строка `main -> main`, через 1–3 минуты — зелёная галочка на https://github.com/Bobryakov/quidly/actions.

## Шаг 3. Телефон

Quidly → плашка **«Вышла новая версия»** → **Обновить**.

- Если PIN ещё не включали: «Настройки → PIN и блокировка → Включить PIN» → 4 цифры → ещё раз те же 4 цифры (после четвёртой цифры Quidly сам переходит дальше).
- Если уже поставили PIN из 5–6 цифр — он продолжает работать. Чтобы перейти на 4 цифры: «Настройки → PIN и блокировка → 🔢 Сменить PIN» → старый PIN → новый из 4 цифр → ещё раз.

✅ **Должны увидеть:** на экране замка — 4 кружка.
