# Этап 6: аналитика — отправить на GitHub и попробовать

Время: около 10 минут. Компьютер: Windows, PowerShell.

Новые файлы я уже положил в папку `quidly`. На этом этапе добавилась библиотека для графиков (Recharts), поэтому в этот раз **нужен `npm install`**.

---

## Шаг 1. Откройте PowerShell в папке проекта

```
cd $HOME\Projects\quidly
```

✅ **Должны увидеть:** строку, которая заканчивается на `\Projects\quidly>`

---

## Шаг 2. Поставьте новые пакеты

```
npm install
```

✅ **Должны увидеть:** строку вида `added 38 packages` (число может отличаться).

ℹ️ В конце появится `14 vulnerabilities (2 moderate, 12 high)`. Это **не** из-за графиков: такие же предупреждения теперь показывает и прошлая версия. Это свежее предупреждение про служебный инструмент поиска файлов, которым пользуются программы сборки и тестов. В само приложение на телефоне он не попадает — я это проверил. **Не запускайте** `npm audit fix --force` — он сломает сборку.

---

## Шаг 3. Прогоните тесты

```
npm test
```

✅ **Должны увидеть:** `Tests  152 passed (152)`.

---

## Шаг 4. Сохраните и отправьте изменения на GitHub

По очереди:

```
git add .
```
✅ Ничего (или предупреждения про `LF`/`CRLF` — это нормально).

```
git commit -m "Этап 6: аналитика"
```
✅ Строка вида `[main 1a2b3c4] Этап 6: аналитика`.

```
git push
```
✅ В конце строка `main -> main`.

---

## Шаг 5. Дождитесь публикации и обновите телефон

1. https://github.com/Bobryakov/quidly/actions — через 1–3 минуты **зелёная галочка** ✅ у запуска «Этап 6: аналитика».
2. На телефоне: Quidly → плашка **«Вышла новая версия»** → **Обновить** (или закройте приложение полностью и откройте снова).

✅ **Должны увидеть:** в нижнем меню «📊 Аналитика» — графики вместо заглушки.

---

## Что попробовать

1. **Период:** вверху — «Месяц» (стрелками можно листать), «3 месяца», «Год».
2. **Прогноз** (для текущего месяца): «При таком темпе потратишь …» и «Можно тратить … в день». Второе появится, если задан бюджет.
3. **Траты по категориям:** кольцо и список с процентами. Тап по категории — откроются её операции.
4. **Доходы и расходы:** столбики за 6 месяцев. Текущий месяц сравнивается честно — с теми же днями прошлого месяца.
5. **Календарь трат:** чем ярче день, тем больше потрачено. Тап по дню — операции этого дня.
6. **Операции:** появились фильтры «Все счета» и «Все категории». «Сбросить фильтры ✕» — вернуть всё как было.

---

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| `npm install` — красные строки `ERR!` | Пришлите скриншот. |
| `npm test` — красные строки `failed` | Пришлите скриншот, ничего не отправляйте на GitHub. |
| В Actions красный крестик ❌ | Нажмите на запуск, затем на красный шаг и пришлите скриншот. На сайте остаётся прошлая рабочая версия. |
| «Аналитика» всё ещё заглушка | Ещё старая версия: закройте приложение полностью и откройте снова. |
| Любая другая ошибка | Скопируйте текст ошибки или сделайте скриншот и пришлите мне. |
