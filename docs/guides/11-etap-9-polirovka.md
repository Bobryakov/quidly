# Этап 9: доводка — отправить на GitHub и проверить

Время: около 10 минут. Компьютер: Windows, PowerShell.

Новые файлы я уже положил в папку `quidly`. Удалять файлы на вашем ноутбуке я отсюда не могу, поэтому ненужный файл с заглушками (`src/pages/PlaceholderPages.tsx`, вы разрешили его удалить) удалите командой в шаге 2. Новых библиотек нет — `npm install` **не нужен**.

---

## Шаг 1. Откройте PowerShell в папке проекта

```
cd $HOME\Projects\quidly
```

✅ **Должны увидеть:** строку, которая заканчивается на `\Projects\quidly>`

---

## Шаг 2. Удалите ненужный файл с заглушками

```
Remove-Item src\pages\PlaceholderPages.tsx
```

✅ **Должны увидеть:** ничего — просто снова строку `…\Projects\quidly>`. Это значит, файл удалён.

(Он остаётся в истории на GitHub — при желании его всегда можно вернуть.)

---

## Шаг 3. Прогоните тесты

```
npm test
```

✅ **Должны увидеть:** `Tests  264 passed (264)`.

❌ Если что-то упало — сохраните текст в файл и напишите мне «упало»:

```
npm test > samples\test-log.txt 2>&1
```

---

## Шаг 4. Проверьте список изменений

```
git status --short --untracked-files=all
```

✅ **Должны увидеть:** файлы программы (`src/…`, `docs/…`, `README.md`), среди них строку ` D src/pages/PlaceholderPages.tsx` (буква **D** — «удалён», так и задумано). И **ни одной** строки с `samples/`.

---

## Шаг 5. Сохраните и отправьте изменения на GitHub

`git add .` запишет в том числе и удаление файла.

```
git add .
```
```
git commit -m "Этап 9: доводка, категории Кредиты и ЖКХ"
```
```
git push
```

✅ В конце строка `main -> main`. Через 1–3 минуты — **зелёная галочка** ✅ на https://github.com/Bobryakov/quidly/actions.

---

## Шаг 6. Обновите приложение на телефоне

Quidly → плашка **«Вышла новая версия»** → **Обновить**.

Если включён PIN — после обновления Quidly спросит его (это новый запуск).

✅ **Должны увидеть:**
- в быстром вводе «+» среди категорий — **🏦 Кредиты** и **🧾 ЖКХ** (перед «Прочее»). Все ваши операции, бюджеты и копилки на месте;
- в «Операциях» начните листать вниз — кнопка «+» уедет вниз и не закрывает суммы; листните вверх — вернётся;
- попробуйте удалить, например, пустую подписку или копилку — вместо серого окна браузера появится окно в стиле Quidly с кнопками «Отмена» и «Удалить».

---

## Шаг 7. Посмотрите список идей

Файл `docs/IDEAS.md` (он же в проекте Claude) — что я заметил, пользуясь приложением «как обычный человек», и что можно сделать дальше. Напишите, какие пункты брать.

---

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Новых категорий нет после обновления | Закройте Quidly полностью (смахните из недавних) и откройте снова. Если вы раньше сами завели категорию «ЖКХ» или «Кредиты» — вторая такая же не появится, так и задумано. |
| `Remove-Item` пишет «не удаётся найти путь» | Значит, файла уже нет. Продолжайте. |
| `npm test` показывает ошибки | Шаг 3: сохраните лог в `samples\test-log.txt` и напишите мне. |
