# Этап 5: копилки — отправить на GitHub и попробовать

Время: около 10 минут. Компьютер: Windows, PowerShell.

Новые файлы я уже положил в папку `quidly`. Новых пакетов нет — `npm install` не нужен.

---

## Шаг 1. Откройте PowerShell в папке проекта

```
cd $HOME\Projects\quidly
```

✅ **Должны увидеть:** строку, которая заканчивается на `\Projects\quidly>`

---

## Шаг 2. Прогоните тесты

```
npm test
```

✅ **Должны увидеть:** `Tests  135 passed (135)`.

---

## Шаг 3. Сохраните и отправьте изменения на GitHub

По очереди:

```
git add .
```
✅ Ничего (или предупреждения про `LF`/`CRLF` — это нормально).

```
git commit -m "Этап 5: копилки"
```
✅ Строка вида `[main 1a2b3c4] Этап 5: копилки`.

```
git push
```
✅ В конце строка `main -> main`.

---

## Шаг 4. Дождитесь публикации

https://github.com/Bobryakov/quidly/actions — через 1–3 минуты у запуска «Этап 5: копилки» будет **зелёная галочка** ✅.

---

## Шаг 5. Обновите приложение на телефоне

Откройте Quidly → плашка **«Вышла новая версия»** → **Обновить**. Если плашки нет — закройте приложение полностью и откройте снова (до двух раз).

ℹ️ Все прежние данные сохранятся — база обновится сама.

✅ **Должны увидеть:** в нижнем меню «🐷 Цели» вместо заглушки — экран «Копилок пока нет» с кнопкой **+ Новая цель**.

---

## Что попробовать

1. **Завести цель:** «Цели» → **+ Новая цель** → название, сколько нужно накопить, при желании — галочка «Есть срок» и дата, значок и цвет → **Сохранить**.
2. **Подсказка:** если срок есть, на карточке появится «Чтобы успеть к …, откладывай X ₽ в месяц».
3. **Пополнить / снять:** тап по цели → **🐷 Пополнить** (есть быстрые кнопки +500 / +1 000 / +5 000) или **↩︎ Снять**. Снять больше, чем лежит, не получится. Ошиблись — **Отменить** в плашке внизу.
4. **Конфетти:** пополните цель до конца — увидите конфетти 🎉, а цель переедет в «Достигнуты».
5. **Главная:** под общим балансом — «🐷 в копилках … · свободно …». Деньги физически остаются на счетах — копилка просто помнит, что они отложены.
6. **1 декабря** в «Итогах ноября» появится вариант **🐷 В копилку**: остаток категории можно отправить в выбранную копилку (или «Всё в копилку» сразу для всех).

---

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| `npm test` — красные строки `failed` | Пришлите скриншот, ничего не отправляйте на GitHub. |
| `git push` пишет `rejected` | Пришлите скриншот — подскажу. |
| В Actions красный крестик ❌ | Нажмите на запуск, затем на красный шаг и пришлите скриншот. На сайте остаётся прошлая рабочая версия. |
| «Цели» всё ещё заглушка | Ещё старая версия: закройте приложение полностью и откройте снова. |
| Любая другая ошибка | Скопируйте текст ошибки или сделайте скриншот и пришлите мне. |
