# Этап 8: PIN, резервная копия, экспорт — отправить на GitHub и включить

Время: около 15 минут. Компьютер: Windows, PowerShell. Телефон: Android.

Новые файлы я уже положил в папку `quidly`. Новых библиотек нет, поэтому `npm install` **не нужен**.

---

## Шаг 1. Откройте PowerShell в папке проекта

```
cd $HOME\Projects\quidly
```

✅ **Должны увидеть:** строку, которая заканчивается на `\Projects\quidly>`

---

## Шаг 2. Прогоните тесты

```
npm test
```

✅ **Должны увидеть:** `Tests  257 passed (257)`. Это займёт 10–40 секунд.

❌ Если что-то упало — сохраните весь текст в файл и напишите мне «упало»:

```
npm test > samples\test-log.txt 2>&1
```

(Файл попадёт в `samples`, а эта папка на GitHub не отправляется.)

---

## Шаг 3. Убедитесь, что выписка не уйдёт на GitHub

```
git status --short --untracked-files=all
```

✅ **Должны увидеть:** список файлов программы (`src/…`, `docs/…`, `README.md`) — и **ни одной** строки с `samples/`.

❌ Если есть строка с `samples/…` (кроме `samples/README.md`) — ничего не отправляйте, пришлите скриншот.

---

## Шаг 4. Сохраните и отправьте изменения на GitHub

```
git add .
```
```
git commit -m "Этап 8: PIN, экспорт и резервная копия"
```

✅ В конце строка `main -> main`. Через 1–3 минуты — **зелёная галочка** ✅ на https://github.com/Bobryakov/quidly/actions.

## Шаг 5. Обновите приложение на телефоне

Quidly → плашка **«Вышла новая версия»** → **Обновить** (или закройте приложение полностью и откройте снова).

✅ **Должны увидеть:** в «Настройках» новый блок — **🔒 PIN и блокировка**, **💾 Резервная копия**, **📤 Экспорт в Excel / CSV**.

---

## Шаг 6. Сначала — резервная копия

Лучше сделать её **до** включения PIN: если PIN вдруг забудется, данные вернутся из копии.

1. **Настройки → 💾 Резервная копия**.
2. По желанию поставьте галочку **«Защитить паролем»** и дважды введите пароль (не короче 6 символов). **Запишите его** — восстановить пароль нельзя.
3. Нажмите **«⤓ Сохранить файл»**.

✅ **Должны увидеть:** плашку «Копия сохранена в «Загрузки» ✅» и строку «Последняя копия: <сегодняшняя дата>».

4. Откройте на телефоне приложение **«Файлы»** (или «Загрузки»), найдите `quidly-kopiya_<дата>.json` и отправьте его в **Google Диск** (долгое нажатие → «Поделиться» → «Диск»). Копия, которая лежит только на этом же телефоне, при его потере не поможет.

Дальше Quidly сам напомнит о копии на главной раз в неделю.

---

## Шаг 7. Включите PIN и отпечаток

1. **Настройки → 🔒 PIN и блокировка → «Включить PIN»**.
2. Наберите 4–6 цифр → **«Далее»** → наберите их ещё раз.
3. Quidly спросит **«Входить по отпечатку?»** → **«Да, по отпечатку»**.
4. Android покажет своё окно и попросит отпечаток. Он может предложить **«Создать ключ доступа»** для `bobryakov.github.io` и сохранить его в аккаунте Google — это нормально. Это только «ключ от двери» Quidly, ваших финансовых данных в нём нет.

✅ **Должны увидеть:** «✅ PIN-код включён» и галочку у «👆 Вход по отпечатку или лицу».

---

## Шаг 8. Проверьте замок

1. Сверните Quidly и подождите **больше минуты**.
2. Откройте снова.

✅ **Должны увидеть:** фиолетовый экран «Введите PIN» и сразу окно отпечатка. После отпечатка (или PIN) — ваш экран, где вы остановились.

Если сворачивали меньше чем на минуту — откроется без PIN. Это настраивается: «Блокировать после выхода из приложения» → Сразу / 1 / 5 / 15 минут.

---

## Шаг 9 (по желанию). Экспорт

**Настройки → 📤 Экспорт в Excel / CSV** → выберите период и формат → **«⤓ Скачать файл»**. Файл появится в «Загрузках» и откроется в Excel или Google Таблицах.

---

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Галочка «Вход по отпечатку» серая, «недоступно» | На телефоне не настроен отпечаток/разблокировка лицом, или браузер старый. Обновите Chrome, проверьте «Настройки Android → Безопасность». PIN работает и без этого. |
| Забыли PIN | На экране замка — «Забыли PIN?». Данные удалятся, потом «Есть резервная копия? Восстановить» на экране знакомства. |
| Пароль копии не подходит | Пароль восстановить нельзя. Сохраните новую копию (с новым паролем или без). |
| Файла копии нет в «Загрузках» | Пришлите скриншот экрана «Резервная копия» после нажатия кнопки. |
| `npm test` показывает ошибки | Шаг 2: сохраните лог в `samples\test-log.txt` и напишите мне. |
