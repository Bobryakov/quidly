# Этап 4: подписки — отправить на GitHub и попробовать

Время: около 10 минут. Компьютер: Windows, PowerShell.

Новые файлы я уже положил в папку `quidly`. Новых пакетов нет — `npm install` не нужен.

---

## Шаг 1. Откройте PowerShell в папке проекта

```
cd $HOME\Projects\quidly
```

✅ **Должны увидеть:** строку, которая заканчивается на `\Projects\quidly>`

---

## Шаг 2. Прогоните тесты

```
npm test
```

✅ **Должны увидеть:** `Tests  113 passed (113)`.

---

## Шаг 3. Сохраните и отправьте изменения на GitHub

По очереди:

```
git add .
```
✅ Ничего (или предупреждения про `LF`/`CRLF` — это нормально).

```
git commit -m "Этап 4: подписки"
```
✅ Строка вида `[main 1a2b3c4] Этап 4: подписки`.

```
git push
```
✅ В конце строка `main -> main`.

---

## Шаг 4. Дождитесь публикации

https://github.com/Bobryakov/quidly/actions — через 1–3 минуты у запуска «Этап 4: подписки» будет **зелёная галочка** ✅.

## Шаг 5. Обновите приложение на телефоне

Откройте Quidly → плашка **«Вышла новая версия»** → **Обновить**. Если плашки нет — закройте приложение полностью и откройте снова (до двух раз).

ℹ️ Счета, операции и бюджеты сохранятся — база обновится сама.

✅ **Должны увидеть:** в «Настройках» новый пункт **🔁 Подписки**.

---

## Что попробовать

1. **Добавить подписку:** «Настройки → Подписки» → **+ Добавить подписку** → название, сумма, как часто, дата следующего списания → **Сохранить**. Категория по умолчанию — 📺 Подписки, её можно сменить (например, на 📱 Связь).
2. **Сумма за месяц:** вверху экрана — сколько все подписки стоят в месяц и в год (годовые и недельные пересчитываются).
3. **Плашка на главной:** если списание в ближайшие 3 дня, на главной появится «Скоро спишется · послезавтра» и кнопка **✓ Проведено** — трата запишется одним тапом, а дата сдвинется на следующий период. Ошиблись — **Отменить** в плашке внизу.
4. **Пропущенное списание:** поставьте дату следующего списания в прошлом (например, месяц назад). На главной появится «Списалось ДД.ММ.ГГГГ?» — **Проведено** (трата запишется той датой) или **Пропустить** (не было списания).
5. **За сколько дней напоминать:** внизу экрана «Подписки» — 1, 3 или 7 дней.
6. **Пауза:** откройте подписку → галочка «На паузе» — напоминаний не будет, в сумму за месяц не входит.

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| `npm test` — красные строки `failed` | Пришлите скриншот, ничего не отправляйте на GitHub. |
| `git push` пишет `rejected` | Пришлите скриншот — подскажу. |
| В Actions красный крестик ❌ | Нажмите на запуск, затем на красный шаг и пришлите скриншот. На сайте остаётся прошлая рабочая версия. |
| В настройках нет «Подписки» | Ещё старая версия: закройте приложение полностью и откройте снова. |
| Любая другая ошибка | Скопируйте текст ошибки или сделайте скриншот и пришлите мне. |
