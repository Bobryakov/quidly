# Этап 3: бюджеты — отправить на GitHub и попробовать

Время: около 10 минут. Компьютер: Windows, PowerShell.

Новые файлы я уже положил в папку `quidly`. Новых пакетов на этом этапе нет, поэтому `npm install` не нужен.

---

## Шаг 1. Откройте PowerShell в папке проекта

```
cd $HOME\Projects\quidly
```

✅ **Должны увидеть:** строку, которая заканчивается на `\Projects\quidly>`

---

## Шаг 2. Прогоните тесты

```
npm test
```

✅ **Должны увидеть:** `Tests  90 passed (90)`.

---

## Шаг 3. Сохраните и отправьте изменения на GitHub

По очереди:

```
git add .
```
✅ Ничего (или предупреждения про `LF`/`CRLF` — это нормально).

```
git commit -m "Этап 3: бюджеты"
```
✅ Строка вида `[main 1a2b3c4] Этап 3: бюджеты`.

```
git push
```
✅ В конце строка `main -> main`.

## Шаг 4. Дождитесь публикации

https://github.com/Bobryakov/quidly/actions — через 1–3 минуты у запуска «Этап 3: бюджеты» будет **зелёная галочка** ✅.

## Шаг 5. Обновите приложение на телефоне

Откройте Quidly → плашка **«Вышла новая версия»** → **Обновить**. Если плашки нет — закройте приложение полностью и откройте снова (до двух раз).

ℹ️ Ваши счета и операции сохранятся: база данных обновляется сама, ничего не стирая.

✅ **Должны увидеть:** на главной под балансом — карточку **«🎯 Задайте бюджет»**.

---

## Что попробовать

1. **Задать лимиты:** тап по «🎯 Задайте бюджет» (или «Настройки → Бюджеты») → в списке «Без лимита» тап по категории → впишите сумму → **Сохранить**.
2. **Общий бюджет:** считается сам как сумма лимитов. Нажмите на карточку «Общий бюджет», чтобы вписать свою сумму, или «Считать как сумму категорий», чтобы вернуть как было.
3. **Цвета:** полоска зелёная, пока потрачено меньше 80%, жёлтая — от 80% до 100%, красная — сверх лимита.
4. **Предупреждения:** запишите трату, которая перевалит за 80% лимита — в плашке появится 🟡 «потрачено 85% лимита»; сверх лимита — 🔴 «лимит превышен на …».
5. **Перенос остатка:** в карточке лимита есть галочка «Переносить остаток». Для «Подарков» её стоит оставить, для «Кафе» можно снять.
6. **Перерасход:** внизу экрана «Бюджеты» — галочка «Переносить перерасход». По умолчанию выключена: каждый месяц начинается без долга.

### Что будет 1 декабря

На главной появится карточка **«📊 Итоги ноября»**: по каждой категории — остаток или перерасход и выбор, что сделать с остатком:
- 🔁 **Перенести** — добавить к лимиту декабря (выбрано по умолчанию);
- 🩹 **Покрыть** — закрыть остатком перерасход другой категории;
- 🧹 **Обнулить** — начать с чистого лимита.

Нажмите **Применить**. Если ничего не делать, после 7 декабря остатки перенесутся сами.

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| `npm test` — красные строки `failed` | Пришлите скриншот, ничего не отправляйте на GitHub. |
| `git push` пишет `rejected` | Пришлите скриншот — подскажу. |
| В Actions красный крестик ❌ | Нажмите на запуск, затем на красный шаг и пришлите скриншот. На сайте при этом остаётся прошлая рабочая версия. |
| На телефоне нет карточки «Задайте бюджет» | Значит, ещё старая версия: закройте приложение полностью и откройте снова. |
| Любая другая ошибка | Скопируйте текст ошибки или сделайте скриншот и пришлите мне. |
