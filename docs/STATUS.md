# Статус проекта Quidly

Обновлено: 17.11.2026

## Где мы сейчас
- **Этап 1 — код готов** и лежит в папке проекта на ноутбуке. Сборка и 12 тестов проходят.
- Ждём владельца: запуск на ноутбуке, создание репозитория, первая отправка на GitHub — по инструкции `docs/guides/02-zapusk-i-publikaciya.md`.
- После того как приложение откроется на https://bobryakov.github.io/quidly/ — этап 2.

## Окружение владельца
- Ноутбук: Windows, PowerShell 5.1.
- Установлены: Git 2.56, Node.js v26. Для npm выполнено `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`.
- Папка проекта: `C:\Users\Bobryakov\Projects\quidly`.
- GitHub: `Bobryakov`, репозиторий `quidly` (создаётся по инструкции 02). Адрес приложения: https://bobryakov.github.io/quidly/
- Владелец не программист: объяснять просто, команды — точные, с ожидаемым результатом. Большие инструкции — файлом в docs/guides/.

## Как работаем
- Код пишется и проверяется (сборка, тесты) в облачной среде Claude.
- Готовые файлы передаются в папку проекта на ноутбуке. Владелец запускает на ноутбуке только короткие команды (установка, запуск, отправка на GitHub).

## Принятые решения
- Название: Quidly.
- Копилки ведутся отдельно от счетов.
- Геймификация: серия дней + 5 бейджей (см. SPEC, раздел 10).
- Забытый PIN: сброс только с удалением данных, затем восстановление из бэкапа.
- Перенос остатка бюджета включён + карточка «Итоги месяца» (SPEC, раздел 5.1).

### Технические решения этапа 1
- Адреса экранов через `#` (`/quidly/#/settings`) — чтобы GitHub Pages не выдавал «страница не найдена» при обновлении.
- Обновление приложения — только по кнопке «Обновить» на плашке, без автоперезагрузки посреди ввода.
- Выбор темы хранится в localStorage (это настройка интерфейса, не финансовые данные). Финансовые данные — в IndexedDB через Dexie, начиная с этапа 2.
- Публикация: GitHub Actions на каждую отправку в `main`; если тесты не прошли — публикации нет.
- `npm audit` показывает 4 moderate-предупреждения в инструментах сборки PWA (workbox → glob). В приложение не попадают; `npm audit fix --force` не запускать — он откатывает vite-plugin-pwa.
