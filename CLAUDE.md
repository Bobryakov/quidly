# Финансовое PWA

Личный учёт финансов. Mobile-first, интерфейс на русском.

## Жёсткие ограничения
- Данные только на устройстве (IndexedDB через Dexie). Никаких серверов, регистрации и аналитики.
- Валюта только ₽. Формат 1 234,56 ₽, даты ДД.ММ.ГГГГ, неделя с понедельника.
- Push-уведомления не использовать, напоминания показывать внутри приложения.
- Схема БД версионируется, изменения только через миграции. Обновления не должны терять данные пользователя.
- Не придумывай форматы банковских выписок. Работай только по реальным примерам из папки samples/.
- PIN хранить только как хеш (PBKDF2 + соль).

## Стек
React + TypeScript + Vite, Tailwind, Dexie, vite-plugin-pwa, Recharts, Framer Motion, SheetJS, PapaParse, Vitest.
Деплой: GitHub Pages через GitHub Actions.

## Дизайн
Яркий, игровой: цветные карточки, эмодзи категорий, анимации. При этом суммы крупные и хорошо читаются. Светлая и тёмная тема.

## Правила работы
- Расчёты (бюджеты, прогноз, цели), парсеры и дедупликацию покрывать тестами.
- После каждого этапа: прогнать тесты, сделать коммит, обновить README.
- Полное описание функций — в docs/SPEC.md.
- Большие инструкции для владельца (больше 3–4 шагов или с командами для терминала) присылать отдельным файлом в docs/guides/ (номер-тема.md), а в чате — короткое резюме и что сделать первым.
